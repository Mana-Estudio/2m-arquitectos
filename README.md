# 2M Arquitectos — web

Sitio estático en Astro, a partir del diseño de Claude Design.

```
npm install
npm run dev      # desarrollo
npm run build    # genera dist/
```

- Datos de proyectos, equipo y blog: `src/data.ts`
- Fotos por proyecto: `src/assets/proyectos/<slug>/` (se optimizan a WebP en el build)

Pendiente del cliente: año, m² y estado de cada proyecto, fotos en alta, fotos del equipo, horario y backend del formulario (hoy abre el correo con la solicitud).
